# Custom earning types

*By Ayesha Konte. Updated May 14, 2025.*

Halvard includes the earning types most businesses need out of the box: Regular, Overtime, Double overtime, Bonus, Commission, Holiday, Paid time off, Sick, Tips, Reimbursement and a few more. If you pay something that doesn't fit, you can create your own.

Common examples we see:

- Shift differential for night or weekend work
- On call pay
- Referral bonus (so it's reported separately from other bonuses)
- Uniform allowance
- Per diem for field staff

## Create a custom earning type

1. Go to Settings > Payroll > Earning types.
2. Click **New earning type**.
3. Give it a name. Employees see this name on their pay stub, so keep it clear.
4. Choose the **tax treatment**. This is the important part. Pick the closest match:
   - *Regular wages* (taxed like normal pay)
   - *Supplemental wages* (taxed like bonuses)
   - *Non-taxable reimbursement*
   - *Non-cash* (taxed but not paid in cash)
5. Choose whether it counts toward overtime calculations.
6. Save.

Not sure about tax treatment? Ask your accountant before you run payroll with it. Changing the tax treatment later doesn't fix payrolls that already went out.

## How many can I create?

If you're on the Starter plan, you can create up to 10 custom earning types. Archived types don't count toward that. If you need more, Core and Plus allow more; see *Compare Halvard plans*.

## Archiving

You can't delete an earning type that has been used in a payroll, because it's part of your pay history. Archive it instead: it disappears from the earnings menu on Run payroll but still shows on past stubs and reports.
